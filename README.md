# Cab Booking Management System

## Project Overview

The Cab Booking Management System is a SQL-based database project designed to manage customers, drivers, cabs, and ride bookings. The project demonstrates how relational databases can be used to store, manage, and analyze transportation service data efficiently.

## Features

- Customer Management
- Driver Management
- Cab Information Tracking
- Ride Booking Records
- Revenue Analysis
- Driver Performance Reports

## Technologies Used

- MySQL
- SQL Queries
- GitHub

## SQL Concepts Covered

- Primary Keys
- Foreign Keys
- Joins
- Aggregate Functions
- Group By
- Order By

## Reports Generated

- Total Revenue
- Most Active Customer
- Highest Rated Driver
- Driver-wise Ride Count
- Cab Usage Analysis
